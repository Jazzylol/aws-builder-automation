# 临时 SSO 授权链接生成

## 🔗 如何为 QQ 邮箱生成 SSO 授权链接

### 方法 1：使用程序生成（推荐）⭐⭐⭐⭐⭐

**步骤**：

1. **打开程序**
   ```bash
   npm run tauri dev
   ```

2. **在账号列表中找到任意一个账号**
   - 不需要是 QQ 邮箱的账号
   - 任何账号都可以

3. **点击"SSO 授权"列的"生成链接"按钮**
   - 程序会生成一个 SSO 授权链接

   - 点击复制按钮（📋）

5. **在浏览器中打开链接**
   - 使用你的 QQ 邮箱账号登录
   - 手动完成授权

6. **获取 Token**
   - 点击"获取 Token"按钮（🔑）

## 🎯 为什么不能直接生成？

### 技术原因

SSO 授权链接的生成需要：

1. **调用 AWS SSO API**
   ```rust
   // 注册 OIDC 客户端
   let client = sso_auth.register_client().await?;
   
   // 获取设备授权码
   let device_auth = sso_auth.start_device_authorization(
       &client.client_id, 
       &client.client_secret
   ).await?;
   
   // 生成授权链接
   let url = device_auth.verification_uri_complete;
   ```

2. **需要运行程序**
   - 我无法直接运行你的程序
   - 我无法调用 AWS API

3. **链接是临时的**
   - 每个链接有效期约 15 分钟
   - 过期后需要重新生成
