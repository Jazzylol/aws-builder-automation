# AWS 验证码邮件获取说明

## 问题原因

AWS 发送的验证码邮件被 Outlook 自动归类到 **垃圾邮件文件夹 (Junk)**，而不是收件箱 (INBOX)。

## 解决方案

检查邮箱时需要同时检查两个文件夹：
- `INBOX` - 收件箱
- `Junk` - 垃圾邮件文件夹

## 关键代码

```javascript
// 检查 Junk 文件夹
imap.openBox('Junk', false, (err) => {
  // 搜索邮件...
});
```

## 验证码邮件特征

| 字段 | 值 |
|------|-----|
| 发件人 | `no-reply@login.awsapps.com` |
| 主题 | `Verify your identity` |
| 验证码格式 | 6位数字 |

## 使用脚本

```bash
# 检查垃圾邮件文件夹中的验证码
node check_junk.mjs
```

## 注意事项

1. AWS 验证码有效期为 10 分钟
2. 每次请求会生成新的验证码，旧验证码失效
3. 建议将 `no-reply@login.awsapps.com` 添加到邮箱白名单，避免邮件进入垃圾箱
