# 更新邮箱凭证使用说明

## 功能说明

这个功能用于批量更新已存在账号的邮箱 OAuth2 凭证（`email_client_id` 和 `email_refresh_token`），**不会影响账号的 Kiro 信息**（如 Kiro 密码、Kiro Token 等）。

## 使用场景

当你的账号已经注册了 Kiro，但邮箱凭证被 SSO 凭证覆盖导致无法获取验证码时，可以使用此功能恢复邮箱凭证。

## 使用步骤

### 1. 准备邮箱凭证数据

确保你有原始的邮箱凭证文件（如 `src-tauri/邮箱凭证.md`），格式为：

```
邮箱地址----邮箱密码----client_id----refresh_token
```

示例：
```
user@outlook.com----password123----9e5f94bc-xxxx----M.C507_BAY.0.U.-CvuEZLOTt...
```

### 2. 打开应用

启动应用后，点击左侧的"导入"标签页。

### 3. 粘贴或导入数据

有两种方式：

**方式 A：直接粘贴**
1. 复制邮箱凭证数据
2. 粘贴到文本框中
3. 点击"更新邮箱凭证"按钮

**方式 B：从文件导入**
1. 将邮箱凭证保存为 `.txt` 文件
2. 点击"从文件导入"按钮
3. 选择文件后会自动填充到文本框
4. 点击"更新邮箱凭证"按钮

### 4. 查看结果

更新完成后会显示结果：
- **成功**: 成功更新的账号数量
- **失败**: 更新失败的账号数量
- **未找到**: 数据库中不存在的账号数量

## 注意事项

### ✅ 会更新的字段
- `email_client_id`: 邮箱 OAuth2 的 client_id
- `email_refresh_token`: 邮箱 OAuth2 的 refresh_token

### ❌ 不会影响的字段
- `email`: 邮箱地址（用于匹配账号）
- `email_password`: 邮箱密码
- `client_id`: SSO client_id（如果已注册）
- `refresh_token`: SSO client_secret（如果已注册）
- `kiro_password`: Kiro 账号密码
- `kiro_refresh_token`: Kiro RefreshToken
- `status`: 账号状态
- `error_reason`: 错误原因

### 匹配规则

- 根据**邮箱地址**匹配数据库中的账号
- 如果邮箱不存在，会跳过该条记录（计入"未找到"）
- 只更新找到的账号的邮箱凭证字段

## 验证更新是否成功

更新完成后，可以通过以下方式验证：

1. **勾选账号复选框**：在账号列表中勾选已更新的账号
2. **自动获取验证码**：系统会自动尝试获取验证码
3. **查看验证码列**：如果显示验证码和时间，说明更新成功

## 常见问题

### Q1: 更新后仍然无法获取验证码？

**可能原因**：
- 邮箱凭证本身已过期
- 邮箱 OAuth2 权限被撤销
- 网络连接问题

**解决方案**：
- 重新获取邮箱的 OAuth2 凭证
- 检查邮箱账号是否正常
- 确认网络连接正常

### Q2: 显示"未找到"是什么意思？

**原因**：数据库中不存在该邮箱地址的账号。

**解决方案**：
- 检查邮箱地址是否正确
- 确认该账号是否已导入到系统中
- 如果需要，先使用"从文本导入"功能导入新账号

### Q3: 会不会覆盖我的 Kiro Token？

**不会！** 此功能只更新邮箱凭证字段，完全不影响 Kiro 相关信息。

### Q4: 可以批量更新吗？

**可以！** 一次可以更新多个账号，每行一个账号数据。

## 技术细节

### 后端实现

```rust
// 命令：update_email_credentials
// 功能：批量更新邮箱 OAuth2 凭证
// 参数：content (String) - 邮箱凭证数据
// 返回：更新结果统计
```

### 数据库操作

```sql
UPDATE accounts 
SET email_client_id = ?, 
    email_refresh_token = ? 
WHERE email = ?
```

### 前端 API

```typescript
api.updateEmailCredentials(content: string): Promise<string>
```

## 完整流程示例

1. **准备数据**：
   ```
   user1@outlook.com----pass1----client-id-1----refresh-token-1
   user2@outlook.com----pass2----client-id-2----refresh-token-2
   ```

2. **执行更新**：
   - 粘贴数据到文本框
   - 点击"更新邮箱凭证"按钮

3. **查看结果**：
   ```
   邮箱凭证更新完成！成功: 2, 失败: 0, 未找到: 0
   ```

4. **验证功能**：
   - 勾选账号复选框
   - 查看验证码列是否显示最新验证码

## 与"从文本导入"的区别

| 功能 | 从文本导入 | 更新邮箱凭证 |
|------|-----------|-------------|
| 用途 | 导入新账号 | 更新现有账号的邮箱凭证 |
| 邮箱存在时 | 报错（重复） | 更新凭证 |
| 邮箱不存在时 | 创建新账号 | 跳过（未找到） |
| 影响 Kiro 信息 | 否（新账号没有） | 否（保留原有） |
| 适用场景 | 首次导入 | 修复凭证问题 |

## 总结

这个功能专门用于修复邮箱凭证问题，让已注册的 Kiro 账号能够重新获取验证码，而不会影响任何 Kiro 相关的信息。使用简单，安全可靠。
